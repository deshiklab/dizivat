# RBS VAT — API contract (v1)

Generated by `scripts/contract.py --doc` from the table the contract tests run against. Base path `/api/v1`.

**Conventions** — JSON bodies; session cookie `rbs_session` (httpOnly). Errors are RFC 9457 `application/problem+json` `{type, title, status, errors?: {field: [code]}}`. 401 = no/expired session, 403 = role lacks the permission (title names it), 404 unknown id, 409 state conflict, 422 validation (field → codes), 429 sign-in locked. Lists accept `page, size, sort=field.asc|desc, q, from, to` and facet params (comma-separated) and return `Page<T> = {data, total, page, size, totals, facets}`; add `format=csv` for an export.
